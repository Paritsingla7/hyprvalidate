# Code of conduct

## The short version

Be decent. This is a small tool for a hobbyist community; nobody is here to
have a bad time.

## Specifics

Expected:

- Assume good faith. Most disagreements here are about a technical detail,
  not about a person.
- Criticise code, not people. "This rename table will drift" is useful.
  "This is stupid" is not.
- Accept that scope is finite. A "no" to a feature isn't a judgement of the
  person asking.

Not acceptable:

- Harassment, personal attacks, or discriminatory language of any kind.
- Publishing someone's private information.
- Sustained disruption of discussions.

## A note specific to this project

This project's docs compare it against other people's converters, with
measured numbers. That comparison is about **code**, and it exists alongside
explicit credit to those projects — see
[`docs/COMPARISON.md`](docs/COMPARISON.md).

Do not use this repo as a place to disparage other tools or their authors.
They shipped working software into a community that needed it, and did it
first. Issues or PRs that are hostile toward another project will be closed.

## Reporting

Open an issue, or if it's not something to raise publicly, use GitHub's
[private report feature](https://docs.github.com/en/communities/maintaining-your-safety-on-github/reporting-abuse-or-spam)
on the repository.

The maintainer may remove comments, commits, issues, and PRs that don't fit
the above, and may block accounts for repeated or severe behaviour.
