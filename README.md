# hyprvalidate

A schema-driven validator (and, eventually, converter) for Hyprland's Lua
config format — checked against Hyprland's own authoritative, autogenerated
API schema, not a hand-typed guess.

## Why

Hyprland moved from the old `hyprland.conf` (hyprlang) format to a Lua-based
config. Migrating an existing config means either hand-translating it or
using one of a handful of community converters — and testing all four found
that three produce output that doesn't even parse as valid Lua, and all four
independently hand-transcribe Hyprland's dispatcher and config-key names
into their own tables, which drift from reality (measured: one tool's
dispatcher table has 53 entries, another 12, another 2 — against the real
count of 51).

Hyprland already ships the real answer: an autogenerated LuaLS type stub
(`hl.meta.lua`) containing every valid config key, its type, and every valid
dispatcher function — regenerated from source on every build, installed
alongside the compositor since the first Lua-capable release. One of the
four existing tools already tries to read it and fails silently (its parser
extracts zero entries — confirmed by reading its source). None of the others
attempt it at all.

hyprvalidate reads that schema properly, and uses it — instead of a
hand-maintained table — to check (and eventually generate) Lua configs.

## Status

Early. The schema extractor (the foundation everything else depends on) is
built and verified against the real installed schema. See
[`docs/PLAN.md`](docs/PLAN.md) for what's built, what's next, and how the
pieces depend on each other.

## Structure

```
hyprvalidate/
  hyprvalidate/           the package
    schema/               extractor: hl.meta.lua -> queryable schema (done)
    hyprlang/             hyprlang (.conf) reader - not started
    luaast/               Lua AST + reader/writer - not started
  tests/
  docs/
    PLAN.md               the build plan - what, why, dependencies
  schema.json             example schema extracted from a real system
```

## Requirements

- A Hyprland install with the Lua config API (v0.55+) — the schema is read
  from `/usr/share/hypr/stubs/hl.meta.lua` by default (path can be overridden).
- Python 3.10+.
